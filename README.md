# mealPlan

Responsive static website for a detailed 7-day Indian meal plan.

## GitHub Pages

This repository is designed to publish directly from the repository root.

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select the default branch (`main`) and `/ (root)`
4. Save

The site is pure HTML/CSS/JavaScript and does not require a build step.

## Included

- 7-day exact meal plan
- Daily macro, mineral and full vitamin dashboard
- 84 Indian-style recipe options
- Batch-prep guide
- Costco / Walmart / Lotte shopping comparison
- Interactive shopping checklist saved in browser local storage
- Criteria audit
- Viruddha-Ahara audit
- Source and methodology notes
- Downloadable source XLSX and PDF files

## Data note

Nutrition values mirror the supplied planning workbooks. They are estimates based on generic food-composition data. Vitamin D remains below the food-only target on most days and should not be corrected by simply increasing cod liver.
